## defects

### D1 — `"private": true` on a published npm package

- **what**: upgrade wrote `"private": true` into `package.json`. no local test fails; the break lands in cicd (publish) and provision (repo visibility)
- **how**: `git diff origin/main -- package.json` → `+  "private": true,` (key was absent on main). `git diff origin/main -- provision/github.repo/resources.ts` → visibility now `pkg.private === false ? 'public' : 'private'` (fail closed)
- **why**: practice `provision-github/bad-practices/implicit-package-privacy` backfills `"private": true` wherever `private` is absent. `npm publish` refuses a private package (EPRIVATE); provision apply on main would flip this public repo private
- **fix**: `package.json` → `"private": false`. explicit boolean, so the practice leaves it alone on future upgrades

### D2 — `.agent/keyrack.yml` left untracked

- **why**: declapract writes the file; the upgrade stages only paths it diffs against tracked state
