## X1 — practice bug

- `3.3.repair.cicd.defects.stone` step 2 prescribes `fix(practs): bump to latest best`
- `git.commit.set` infers level from the branch name and refuses a `fix` header on a `feat-*` branch: `✋ ConstraintError: commit prefix mismatch … level.bound = feat (inferred)`
- the stone should name the header as `$level(practs): …`, or tell the driver to match the branch level

## X2 — host quirk

- `rhx keyrack unlock --owner ehmpath --env prep --key EHMPATHY_SEATURTLE_GITHUB_TOKEN` → `status: absent`
- director invoked the auth-as-human stopgap; pr #19 opened under the human gh login, commit stays seaturtle[bot]
- fix: a human runs `rhx keyrack fill --owner ehmpath --env prep --key EHMPATHY_SEATURTLE_GITHUB_TOKEN`. no practice change owed
