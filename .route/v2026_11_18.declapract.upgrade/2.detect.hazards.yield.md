## live hazards

### H1 — `package.json` gains `"private": true` · config + cicd · 🔴 confirmed

- **what changed**: template backfills `"private": true` where `private` is absent
- **why it breaks**:
  - `.publish-npm.yml` runs `npm publish --access public --provenance`; npm refuses any package with `"private": true` (EPRIVATE). next release would fail to publish
  - `provision/github.repo/resources.ts` maps `visibility: pkg.private === false ? 'public' : 'private'`. on merge to main, provision apply flips this public repo private
- **known**: same defect hit `ehmpathy/as-command` (route `v2026_11_16.declapract.upgrade`); template brief `rule.forbid.fail-open-publicity` says a published package declares `"private": false`
- **verify**: `package.json` holds `"private": false`; provision plan in pr ci shows no visibility change
